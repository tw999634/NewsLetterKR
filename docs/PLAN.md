# 테크 뉴스레터 프로젝트 계획

> 한국어·영어로 테크 뉴스를 수집하고, 일본어 뉴스레터로 정리해 Notion 웹페이지에 발행한다.

## 목표와 범위

- **독자:** 일본어로 테크 동향을 읽는 사람
- **입력:** 승인된 웹 소스의 공식 발표, 논문·모델 카드, 프로젝트 릴리스와 공개 커뮤니티의 후보 정보
- **출력:** 출처를 명시한 일본어 Markdown 완성본과 뉴스레터 한 호당 새로 작성하는 Notion 하위 페이지. 상위 위치는 사용자가 지정한 [【뉴스레터】GitHub Trending](https://app.notion.com/p/GitHub-Trending-4197cfd0ca688017a33bc594146e02d4) 페이지다. 게시용 연결 권한과 공개 방식은 [관리자 요청 사항](NOTION_ARTICLE_ADMIN_REQUEST.md)에 따라 확인한다.
- **운영:** 관리자 검토와 피드백을 거쳐 수정·발행하고, 피드백을 다음 호의 선정·작성 기준에 반영
- **발행 주기:** 매주 토요일, 주 1회. 기준 시간대는 한국 시간(KST)이며 정확한 발행 시각은 추후 정한다.

### 다룰 뉴스

1. 한국에서 화제가 된 테크 뉴스
2. GitHub 등 국제 커뮤니티에서 주목받은 프로젝트
3. AI 뉴스
4. 기타 주요 테크 뉴스

3·4번은 기존 `LLM 모델을 포함한 주요 테크 뉴스` 범주를 나눈 제안이다. 한 이슈는 한 호에서 대표 카테고리 하나에만 싣는다. AI 관련 한국 기사나 GitHub 프로젝트는 먼저 AI 뉴스 후보로 표시하고 최종 분류는 편집자가 정한다. 미확정 기준은 [AI 뉴스 자동화 계획](AI_NEWS_AUTOMATION_PLAN.md)에 정리했다.

`AI 뉴스`의 웹 수집·분석·정리 시스템은 [주간 AI 뉴스 자동화 계획](AI_NEWS_AUTOMATION_PLAN.md)에 정리했다.

토요일 발행을 기준으로 지난 한 주의 후보를 모은다. 후보마다 **원문 URL, 최초 발표일, 발견한 소스, 주목 근거, 확인에 사용한 1차 자료**를 남긴다. 검색량·추천 수·별 수는 선정 참고 신호이며, 단독으로 뉴스 가치나 사실성을 확정하지 않는다.

AI 뉴스는 모델·연구, 제품·API, 개발 도구, 산업·정책의 의미 있는 변화를 다룬다. 해당 집계 기간의 새 발표·출시·중요한 변경인지 확인하고, 회사 발표의 성능·비용 수치는 발표 주체와 조건을 함께 적는다. 원자료·날짜·핵심 수치를 확인하지 못하면 발행을 보류한다. 오래된 자료가 다시 인기 목록에 올랐다는 사실만으로 새 발표로 쓰지 않는다.

[Hacker News](https://news.ycombinator.com/)의 Show HN과 Product Hunt는 GitHub Trending 밖의 프로젝트를, Techmeme는 여러 매체가 다룬 사건을 찾는 데 보완적으로 사용한다. [디스콰이엇](https://disquiet.io/)은 제품 발견에 참고할 수 있으나 현재 주간 인기 순위 소스로 취급하지 않는다. AI 뉴스 수집·분석의 구체적인 소스와 운영 기준은 [자동화 계획](AI_NEWS_AUTOMATION_PLAN.md)에 둔다.

## 제작 흐름

1. **수집:** 한국어·영어 자료를 모으고 원문 URL, 제목, 발행일, 수집일, 언어, 카테고리와 주목받은 근거를 기록한다.
2. **선정:** 독자 관련성, 시의성, 출처의 신뢰도, 새로움으로 후보를 고른다. 중복 보도는 하나의 주제로 묶고, 중요한 사실은 가능하면 공식 발표나 원자료로 확인한다.
3. **요약:** 확인된 사실, 배경, 핵심 변화, 독자에게 의미 있는 점을 짧게 정리한다. 추측과 확인되지 않은 내용은 구분한다.
4. **일본어 작성:** 단순 직역 대신 일본어 독자에게 자연스러운 기사로 재구성한다. 제품명·기술 용어·수치·날짜를 원문과 대조하고, 과장된 표현을 피한다.
5. **검토 및 수정:** 사실관계와 핵심 수치를 원출처로 확인한다. 관리자 피드백에 따라 선정, 문체, 길이, 설명 깊이를 수정한다.
6. **발행:** 승인된 Markdown을 Notion 웹페이지에 반영하고 제목, 링크, 서식, 일본어 표현을 최종 확인한다.

## 기사 초안 형식

각 호는 아래 형식을 기본으로 한다. 실제 분량과 항목 수는 시범 발행 후 조정한다.

```markdown
# テックニュースレター — YYYY年MM月DD日

## 今号のハイライト
- 要点を1行で紹介

## ニュース
### 記事タイトル
カテゴリ: 韓国の話題 / 注目プロジェクト / AIニュース / その他のテックニュース

何が起きたかを簡潔に説明する。

**注目ポイント:** 日本語の読者にとっての意味や背景を説明する。
**出典:** [原文タイトル](https://example.com)
```

원문을 길게 옮기지 않고 자체 요약·해설을 작성한다. 원문 링크와 필요할 때 발표일을 함께 남긴다.

## 단계별 진행

| 단계 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1. 편집 기준 정리 | 대상 독자, 호당 기사 수, 문체, 선정 기준, 검토 담당 확정 | 토요일 주간 발행에 사용할 기준 문서 마련 |
| 2. 시범호 | 승인된 범주에서 후보를 모아 요약·일본어 초안 작성 | 출처가 확인되는 Markdown 초안 완성 |
| 3. 피드백 반영 | 관리자 검토를 반영해 형식·품질 기준 수정 | 수정된 초안과 반복 가능한 작성 절차 확보 |
| 4. Notion 발행 흐름 | Markdown을 Notion 페이지에 옮기는 방식과 승인 절차 결정 | 검토를 마친 시범호를 정상적으로 게시 |
| 5. 반복 작업 개선 | AI 뉴스 웹 수집·중복 확인·근거 추출을 단계적으로 자동화하고 다른 범주로 확장 여부 검토 | 소스 누락과 근거를 확인할 수 있는 주간 실행 및 관리자 검토 흐름 확보 |

## 아직 결정할 사항

- 토요일 발행 시각, 호당 기사 수, 일본어 문체와 목표 분량
- 소스별 우선순위와 선정 기준에 적용할 구체적 수치·조건
- 피드백 전달·승인 방식
- Notion 하위 페이지의 제목·본문 형식, 게시용 연결 권한, 공개·승인 방식
- 자동 하위 페이지 작성의 세부 확인 항목은 [관리자 요청 사항](NOTION_ARTICLE_ADMIN_REQUEST.md)에 정리했다.
- 수집·작성 자동화의 범위와 사용 도구
- 실행 환경과 서버 구성. Cloudflare 등 클라우드 서비스는 후보로만 두고, 시범 운영을 통해 필요한 기능이 확정된 뒤 결정

- GeekNews 자동 수집은 첫 화면 순위 대신 공식 RSS의 최신 글 순서를 사용한다. 운영 서버, Discord 봇, 일본어 변환, Notion 발행은 별도 단계로 남긴다.
